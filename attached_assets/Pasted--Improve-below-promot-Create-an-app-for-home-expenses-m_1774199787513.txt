Here’s a cleaner, more structured, and more “developer-ready” version of your prompt:

Prompt: Home Expense Management App

Design and develop a modern Home Expense Management Application with a vault-based financial tracking system.

Core Concept
The app should have a Main Vault (overall balance).

Users can create multiple child vaults under the main vault, such as:

Home Expenses

Home Construction

Marriage Expenses

Custom categories

Vault Behavior
Each vault should:

Maintain a current balance

Track all transactions:

Add (credit)

Use (debit)

Automatically update the balance after each transaction

Example Scenarios
Home Expenses Vault

Initial: 1000

+5000 → 6000

-1000 → 5000

+6000 → 11000

Home Construction Vault

Initial: 5000

+1000, +4000, +10000, +3000

-2000, -1000, -6000

+1000

Final balance calculated dynamically

Main Vault

Should reflect aggregated balance or independent tracking (configurable)

Key Features
Search Functionality

Search transactions by amount, date, vault, or keyword

User Management

Add/remove users to:

Main vault

Individual child vaults

Role-based access (Admin / Member)

Image Upload

Attach receipts or proof images to transactions

Export Feature

Export full vault data (transactions + balances) to Excel

Authentication

Login using:

Email ID

Mobile number (OTP-based)

UI/UX

Clean, modern, mobile-first interface

Dashboard showing:

Total balance

Vault-wise breakdown

Recent transactions
